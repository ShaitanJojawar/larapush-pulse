High-performance Web Push Notifications with FCM Topics (10M+ users scalability, zero token loops).

== Description ==

LaraPush Pulse enables WordPress website owners to send unlimited web push notifications to their visitors with zero monthly fees.

Features:
* Unlimited subscribers & unlimited push notifications
* Push on Publish: Automatically broadcast newly published articles
* Floating Bell Widget & 2-Step Permission Prompts
* Real-time click tracking & analytics
* Instant 1-API-call broadcast via Google FCM Topics

== Installation ==

1. Upload the `larapush-pulse` folder or `.zip` to your `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to LaraPush Pulse -> Settings.
4. Enter your LaraPush Server URL and Project ID.
5. Save settings.
